BurntToast (Chocapic13' Shaders edit)

Base shaderpack:
  Chocapic13 / Choca_13 - Chocapic13' High Performance Toaster
  https://www.curseforge.com/minecraft/shaders/chocapic13-high-performance-shaders
  Original lighting, shadows, sky lookup tables, tone mapping and geometry programs.
  Original modification notices are retained in the source.

Borrowed material and displacement:
  MLGImposter / mlgimposter and NoComment / NoComment1105 - YoFPS
  https://github.com/NoComment1105/YoFPS-Chocapic13-edit
  https://www.curseforge.com/minecraft/shaders/yofps-shader-chocapic13-edit
  Transparent-water color/opacity construction and optional two-wave displacement.
  Ported from the supplied YoFPS High reference, not the current upstream revision.

Borrowed motion blur:
  Thompie__ - CH Motion V4
  https://www.curseforge.com/minecraft/shaders/ch-motion
  MotionBlur.glsl and final.vsh copied byte-for-byte from the supplied archive.
  BurntToast supplies only an outer optional hand-mask adapter.

Adapted End sky:
  EminGT / Complementary Development - Complementary Reimagined r5.9.3
  https://www.complementary.dev/shaders/
  End star field, endSkyColor palette, BeamNoise construction and noise.png.
  Beam-dependent attenuation, volumetric beams, ray marching, flashes and other
  heavy effects are omitted. Upstream license retained in licenses/.

References and inspiration (no code copied):
  X0nk and the Bliss contributors - Bliss Shader
  https://github.com/X0nk/Bliss-Shader
  Repository layout, small-sample blur and feature/profile organization reference.
  Bliss code is not included in this pack.

Documentation:
  IrisShaders contributors - ShaderDoc and Iris
  https://deepwiki.com/IrisShaders/ShaderDoc
  https://github.com/IrisShaders/ShaderDoc
  https://github.com/IrisShaders/Iris
  Uniforms, dimension routing, program fallbacks and translucent hand rendering.
